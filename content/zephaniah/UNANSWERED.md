# Zephaniah: reader questions no source answered

Questions a reader would ask that no source read answered, by chapter: a list for a later deepening pass. Kept out of `BRIEF.md` so the brief stays brief.

- **1:** Zeph. 1:11: what the place name Maktesh means. Only Keil discusses it, and the writer left it out to keep Keil's share down; Zeph. 1:15: whether the hymn 'Dies irae' comes from this verse. No source read ties the hymn to the verse, so it is left out.
