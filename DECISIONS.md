# Decisions that frame the site

Choices that shape the whole site and that later work shouldn't quietly undo. Only framing decisions go here; the history of how work was done lives in git, not in files. Where a decision is spelled out elsewhere, this file points there.

- **Sourcing is part of writing (2026-09-30).** Content is written so that it needs no audit afterward: every factual claim rests on a source actually read. See `STANDARDS.md` §4.
- **Evidence ledgers are kept permanently (2026-09-30).** Each chapter's `content/<book>/evidence/NN.yaml` is the support for what the chapter currently says, not a record of how it was written. It stays in the repository and is updated when a note changes, and `check-content.mjs` relies on it. See `STANDARDS.md` §5.
- **Stay near Latter-day Saint theology; not a compendium (2026-10-01).** Each chapter centers on the text read in the light of Restoration scripture and latter-day prophets; outside scholarship serves that and doesn't survey the field. A peripheral detail is cut, not sourced. See `STANDARDS.md` §1 and §4.
- **Most content comes from the Church's own sources (2026-10-02).** Then BYU publications, Scripture Central and the Interpreter Foundation's journal (added 2026-10-07); other commentary sparingly, when those have no answer. Everything follows the Church's teaching and doctrine. See `STANDARDS.md` §1.
- **No Wikipedia, other wikis, or popular history websites (Livius.org) as sources.** See `STANDARDS.md` §4.
- **No length target (2026-10-01).** Chapters have no set number of notes or words; notes that are mostly cross-reference chains or curiosities are cut instead. See `STANDARDS.md` §3 (“Selectivity”).
- **Unsourced devotional readings are cut (2026-10-01).** A devotional reading stays only when scripture, a Church source, or a scholar supports it. See `STANDARDS.md` §3.
- **A theme page is an arc across chapters that points to Christ (2026-10-01).** Broader than a chapter, few per book, and worth writing only if it helps the reader see the bigger story that points to Jesus Christ. The text supplies the pattern; scripture and Church sources supply the meaning. On theme pages only, the site may make connections between passages that no published source makes, without inventing doctrine or contradicting what has been revealed (author, 2026-10-03; this replaced “the site adds no readings of its own”). See `STANDARDS.md` §8.
- **No personal application (2026-09-30).** The “Liken it” sections were removed; that belongs in *Come, Follow Me*. See `STANDARDS.md` §1.
- **Every book shares one standard and one codebase.** Book-level choices go in `content/<book>/BRIEF.md`; the code has no book-specific assumptions (books are discovered from `content/*/book.yaml`; see `DEVELOPMENT.md`).
- **Each completed book receives one author-approved illustration in a shared visual language (2026-10-04).** A post-authoring AI stage distills the finished book into a proposed visual brief, then has Codex draw one candidate from it (`scripts/book-art.mjs`). The author approves the candidate before it becomes a site asset; generation never runs as part of a build. See `DEVELOPMENT.md`, “Book illustration workflow.”
- **Content goes to `main`; changes to how the site looks wait for the author's approval** on a separate branch. See `AUTHORING.md`.
- **Process notes are temporary.** Status, plans, audit tracking, and open questions are kept while the work is under way and deleted when it is done. The project files say what is true now and what the rules are; how the work got there is in git (author, 2026-10-09).
