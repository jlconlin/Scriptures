# Review tasks

One line per page, no prose; the reasons are in `REVIEW.md` and in git. A session updates a page's state in the commit that changes the page. States: **todo**, **done** (rewritten, in preview), **live**, **deleted**, **merged →** (into the page named), **later** (bin C and the guides: rewritten after A and B, when the author says).
